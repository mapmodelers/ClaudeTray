# WebView2 SDK binaries

`Microsoft.Web.WebView2.Core.dll`, `Microsoft.Web.WebView2.WinForms.dll` and `x64|arm64\WebView2Loader.dll`
from the Microsoft WebView2 SDK **1.0.3856.49** (Authenticode-signed by Microsoft; redistributable under the
WebView2 SDK license). Taken from the pywebview 6.2.1 wheel, which ships them unchanged.
They host the tray's panel in the WebView2 runtime that comes with Windows 10/11 (Evergreen).
